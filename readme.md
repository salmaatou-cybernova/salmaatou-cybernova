## About

Cybersecurity engineer specializing in security operations, web application testing, and Active Directory security. Experienced in identifying, analyzing, and responding to real-world threats — combining defensive monitoring with an offensive mindset to understand how systems actually break.

<img src="https://capsule-render.vercel.app/api?type=rect&color=0:1a1a2e,100:D4879C&height=3&width=800" />

## Focus Areas

**Security Operations (SOC)**
Log analysis and correlation · alert triage and incident response · threat hunting mapped to MITRE ATT&CK · detection engineering and SOAR playbooks · network traffic analysis

**Web Application Security**
OWASP Top 10 (injection, broken authentication, XSS, SSRF, IDOR, access control flaws) · manual and automated penetration testing · business logic and authentication flaw discovery · vulnerability reporting and remediation guidance

**API Security Testing**
REST and GraphQL security assessment · OWASP API Security Top 10 · JWT and token misconfiguration analysis · broken object-level authorization and excessive data exposure testing

**Active Directory Security**
Domain enumeration and attack path mapping · Kerberoasting, AS-REP Roasting, Pass-the-Hash/Ticket · GPO misconfiguration and privilege escalation analysis · AD hardening and Tier-0 asset protection
